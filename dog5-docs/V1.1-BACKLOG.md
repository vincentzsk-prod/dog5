# DØG-5 — what's left for this version, and everything for v1.1 and later

**22 Nov 2026, §1 rewritten 23 Nov.** One list, gathered from the whole project: the repo (`CLAUDE.md`, every batch record, the voicing
README and cards, `PERF-BASELINE.md`), the Project docs (build log, next-round spec, build kit, character brief,
chapter specs, base-and-ui decisions, presets, device test) and the chats since 16 Oct. When an idea comes up, it goes
here; when an item is done or dropped, it's marked here, not deleted.

**How to read it.** §1 is what still stands between now and the public release (v0.5). §2 is v1.1: the pass after the
first public release, built from playing the unit hard. §3 is later or bigger. §4 lists the engine's known limits,
which only an engine change would move. §5 lists ideas that were decided against, so they don't come back by accident.
Each line says where it came from and what it costs, as far as anyone knows. **Nothing in §2–§3 is approved to build.**
Vincent picks.

## 4. The engine's known limits (accepted; only an engine change moves them)

No Poly-Mod (X-MOD is OSC 2 → OSC 1 FM). No sub-oscillator. No ring mod. No triangle or sine oscillator. No sine or
quadrature LFO, and one LFO shared by every destination (no true Leslie). No per-partial envelope (no crystalline bell
tail). No freeze, reverse or pitch-shifted repeats. PWM depth in the 150–400 Hz band tops out near 10 dB through a murky
filter. The BBD time has no LFO (no chorus from the delay). The tape deck sits after the echo and spring. MORPH works on
TYPE SEM only. UNISON plays one note at a time. A0–A1 are mostly below what small speakers reproduce.

## 5. Decided against, or closed (so they don't come back by accident)

- **Tap tempo** — scrapped (18 Nov). The tempo is GLOBAL knob 1 and the MIDI clock.
- **The ENV "Drone Latch"** — closed: REC is HOLD, the same latch as the ARP hold (18 Nov).
- **The sequencer** — deleted on purpose (tone and simplicity over features). Asked about again 18 Nov; the transport
  buttons now do STOP / TAPE STOP / HOLD.
- **ALGORITHM for voice mode** — no: it is the SLOP ride. Mode is on the MONO / POLY keys.
- **A scrolling OP1–OP6 menu** — no: zero menu-diving. The keybed shortcuts do it.
- **A web editor** — not built for v1.0 (21 Oct, base-and-ui decisions §7.3). The Kennel (§2.3) would revisit it.
- **FLEAS changing the sound** in v1.0 — no (21 Nov); see §2.1.
- **Raising beam-path clashes with the art** — Vincent's call: the beam may sink into the painting.
- **The identity `FM-1_3645_V6.3.5`** — not possible: installers read `NAME_digits` (Batch 27).
